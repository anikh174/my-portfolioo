## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/yourusername/portfolio.git
```

### Go to project directory

```bash
cd portfolio
```

### Install dependencies

```bash
npm install
```

### Start development server

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
